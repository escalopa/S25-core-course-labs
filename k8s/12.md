# Lab 12: Kubernetes ConfigMaps

## Overview

Lab 12 focuses on managing non-confidential configuration data in Kubernetes using ConfigMaps. This lab implements:
- Application persistence (visit counter)
- ConfigMap-based file mounting
- ConfigMap-based environment variables

---

## Task 1: Application Persistence

### 1.1 Upgrade Go Application (Wordle Game)

**Modified files:**

- `app_go/main.go` - Added visit counter logic and `/visits` endpoint
- `app_go/README.md` - Updated documentation

**Key Changes:**

- Added `visitCount`, `visitMutex`, and `visitsFilePath` variables
- Implemented `loadVisitCount()` - Loads visit count from `/data/visits` file on startup
- Implemented `saveVisitCount()` - Persists counter to file
- Implemented `incrementVisits()` - Thread-safe counter increment
- Added `VisitsHandler()` - New endpoint returning JSON with visitor count
- Modified `IndexHandler()` - Increments visit count on each game start

**Visits Tracking:**

- File location: `/data/visits`
- Persists across container restarts
- Thread-safe with mutex locks

### 1.2 Upgrade Python Application (Moscow Time)

**Modified files:**

- `app_python/app.py` - Added visit counter logic and `/visits` endpoint
- `app_python/README.md` - Updated documentation

**Key Changes:**

- Added `VISITS_FILE = "/data/visits"`
- Implemented `load_visits()` - Loads counter from file on startup
- Implemented `save_visits()` - Persists counter to file
- Implemented `increment_visits()` - Increments and saves counter
- Added `/visits` endpoint returning JSON with visit count
- Modified root `/` endpoint - Increments counter on each access

### 1.3 Docker Compose Updates

**Updated: `docker-compose.yml`**

Added volume mounts for both applications:

```yaml
volumes:
  - ./app_python/data:/data  # Python app visits
  - ./app_go/data:/data      # Go app visits
```

**Local Testing:**

```bash

# Access applications
curl http://localhost:5000          # Moscow Time
curl http://localhost:5000/visits   # Visit count
curl http://localhost:8080          # Wordle Game
curl http://localhost:8080/visits   # Visit count

```

### 2.2 Create ConfigMap Manifests

**Created: `k8s/moscow-time-app/templates/configmap.yaml`**
```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "moscow-time-app.fullname" . }}-config
  labels:
    {{- include "moscow-time-app.labels" . | nindent 4 }}
data:
  config.json: |
    {{- .Files.Get "files/config.json" | nindent 4 }}
```

**Created: `k8s/wordle-game/templates/configmap.yaml`**
```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "wordle-game.fullname" . }}-config
  labels:
    {{- include "wordle-game.labels" . | nindent 4 }}
data:

    {{- .Files.Get "files/config.json" | nindent 4 }}
```

### 2.3 Update Deployments with Volumes

**Updated Deployments:**

- `k8s/moscow-time-app/templates/deployment.yaml`
- `k8s/wordle-game/templates/deployment.yaml`

Added volume mount and volume definitions:
```yaml
volumeMounts:
  - name: config
    mountPath: /config
    readOnly: true

volumes:
  - name: config
    configMap:
      name: {{ include "chart.fullname" . }}-config
      items:
        - key: config.json
          path: config.json
          mode: 0644
```
