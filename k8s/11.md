## Task 1: Kubernetes Secrets and Resource Management

### Step 1: Create Secrets Using Helm

Created `secrets.yaml` files in both Helm chart templates:

**File: `moscow-time-app/templates/secrets.yaml`**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: {{ include "moscow-time-app.fullname" . }}-secret
  labels:
    {{- include "moscow-time-app.labels" . | nindent 4 }}
type: Opaque
data:
  MY_PASS: {{ .Values.secret.password | b64enc }}
  MY_USER: {{ .Values.secret.username | b64enc }}
  APP_SECRET: {{ .Values.secret.appSecret | b64enc }}
```

### Step 3: Manage Secrets with Helm

Updated both Helm deployments to use secrets in environment variables:

**Updated deployment.yaml to include env section:**
```yaml
env:
  - name: MY_USER
    valueFrom:
      secretKeyRef:
        name: {{ include "moscow-time-app.fullname" . }}-secret
        key: MY_USER
  - name: MY_PASS
    valueFrom:
      secretKeyRef:
        name: {{ include "moscow-time-app.fullname" . }}-secret
        key: MY_PASS
  - name: APP_SECRET
    valueFrom:
      secretKeyRef:
        name: {{ include "moscow-time-app.fullname" . }}-secret
        key: APP_SECRET
  {{- with .Values.env }}
  {{- toYaml . | nindent 12 }}
  {{- end }}
```

### Step 3: Configure Vault Secrets

**Retrieve Vault dev root token:**
```bash
Dev Root Token: root
```

**Set up secrets engine and create test secret:**
```bash
$ kubectl exec vault-0 -- vault secrets enable -path=secret kv-v2
Success! Enabled the kv-v2 secrets engine at: secret/

$ kubectl exec vault-0 -- vault kv put secret/data/myapp/config \
  username="myuser" \
  password="mypassword" \
  database_host="db.example.com" \
  database_port="5432"
```
